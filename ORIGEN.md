# Origen de esta copia

Este repositorio es una copia privada de **Open BI Artifacts**
(https://github.com/dimaurizzio/open-bi-artifacts), tomada el 21-10-2026 desde la
versión `v0.1.0` (rama `main`), con su historial completo.

- El código original está bajo la licencia Apache 2.0. `LICENSE` y `NOTICE` se
  mantienen sin cambios y el crédito es de sus autores.
- Los archivos que Toro Data modifique deben indicarlo (sección 4.b de la licencia),
  por ejemplo con una línea en el encabezado o en este archivo.
- No se usa el nombre ni la marca del proyecto original para sugerir respaldo de sus
  autores.
- Este repositorio es independiente de `toro-data/toro-data-plataforma`: no comparte
  código, base de datos ni despliegue con FEGOSA ni con la demo de Comercial Andina.

## Traer cambios del original

```
git remote add upstream https://github.com/dimaurizzio/open-bi-artifacts
git fetch upstream
git merge upstream/main
```
